## 🎓 教学使用说明

> 本工具是《新闻传播AI应用教程》（中国人民大学出版社）配套在线实验平台工具，属于**篇Ⅳ 反思篇 · 第14章 新闻传播中的AI伦理**（教材 Tier 2 实验工具）。教材命名："主编的选题决策训练器"。

**学习目标**：在 20 张稿件线索的"发布/扣留"决策中体会公信力与流量的张力，形成一条自己能够说明依据的选题把关标准。

**核心术语**：把关人（Gatekeeper）、新闻价值（News Values）、公信力（Credibility）

**适合对象**：新闻传播专业学生 / 媒体从业者

**课前准备**：打开即用、离线可用；准备纸笔或表格，用于记录每张卡的决策理由。

**课堂流程建议（40 分钟，符合教材"单工具课堂可完成"标准）**
1. **演示导入**（8 分钟）：教师用键盘方向键现场划卡演示前 2 张（如"仅 8 秒且无上下文的执法视频"），故意流量优先直接发布，让学生看到公信力条下跌，同时讲解左滑＝扣留、右滑＝发布与双指标计分规则。
2. **上手实操**（20 分钟）：学生独立完成 20 张线索卡的划卡决策 → 查看结局评价（标杆主编/严谨主编/流量猎手/两难困境）与决策日志 → 对照日志各找出 1 条"因追流量而误发"与 1 条"因保守而错失" → 把其中 3 条的教训改写成一句"编辑部发稿守则" → 刷新重玩，验证新守则能否让公信力提高且流量不低于 50。
3. **小组讨论**（8 分钟）：竞对媒体已抢发一条未经核实的爆款，你跟不跟？——当"不发就失去读者，发就伤害公信力"时，主编的权柄应该对谁负责：老板、读者，还是事实本身？
4. **总结**（4 分钟）：把关不是在公信力与流量之间找平衡点，而是先守住"未核实不发布"的底线，再谈传播效果。

**课后作业**：仿照工具卡片格式自制 3 张"两难稿件卡"（写明发布/扣留各自对公信力与流量的增减数值），在班内交换试玩并互评数值设置是否合理。

**评价建议**：实操完成度 40% · 分析深度 40% · 反思质量 20%
